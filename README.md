# IoT Sensor Data Ingestion System

## Project Description
A MuleSoft-based integration solution for ingesting, validating,
processing, and storing IoT sensor data.

## Architecture
1. Telemetry Ingestion API
2. Telemetry Processing API
3. Telemetry System API
4. Anypoint MQ
5. MySQL Database

## Technologies
- MuleSoft Anypoint Studio
- Mule Runtime 4.12.2
- RAML
- DataWeave
- Anypoint MQ
- MySQL
- MUnit
- Postman

## Git Workflow
main -> develop -> feature branches

## Team Development
Each team member develops an independent module
using a dedicated feature branch.
